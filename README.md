# BuildLab — Student Project Guide

A responsive, multi-page static website introducing students to practical project planning and project ideas. The pages use semantic HTML5 landmarks and a consistent navigation menu.

## Pages

- `site/index.html` — Home and project journey
- `site/projects.html` — Project ideas
- `site/process.html` — Project workflow
- `site/about.html` — About the guide
- `site/styles.css` — Shared responsive styles

## View locally

Open `site/index.html` in a browser. The site has no build step or external dependencies.

## GitHub

Initialize the repository, commit the starter site, then connect a GitHub repository:

```sh
git init
git add .
git commit -m "Initial commit: BuildLab student project guide"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```
